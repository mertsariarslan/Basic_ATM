# Simple ATM Simulator 🏧

This is a console-based ATM simulation program developed during **my first year** as a Computer Engineering student at Ankara Medipol University. It serves as a foundational project to practice basic control flows, loop structures, and user input handling in Java.

## 📌 Features
- 💰 **Deposit:** Add money to the current balance.
- 💸 **Withdraw Money:** Deduct money from the current balance.
- 🏦 **Balance Inquiry:** Check the real-time account balance.
- 🔄 **Continuous Loop:** The application keeps running until the user explicitly chooses to exit.

## 🛠️ Technologies Used
- **Language:** Java
- **Core Concepts:** `while` loops, `switch-case` statements, Console I/O
- **Libraries:** `java.util.Scanner`
